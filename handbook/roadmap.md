# Roadmap

**Now (pilot build):** Oulu forests, bilberry and lingonberry, unvalidated ecological baseline, heuristic season stage, trip planner, field reports, admin dashboard, subscriptions scaffolding.

**Before the 2027 season**
1. CDSE credentials and the Python raster job: Sentinel-2 NDVI/NDMI seasonal composites into `satellite_features`.
2. Self-hosted OSRM and Nominatim; National Land Survey key for aerial imagery and terrain.
3. Written data request to Luke; agree a field protocol with a university group.
4. Billing and tax configuration; real checkout test.
5. Offline-friendly Field mode (service worker, saved-area tiles).

**During the season:** collect labels; train and validate; promote only a model that beats the baseline on held-out blocks.

**After:** Model B on verified flowering/ripeness labels; cloudberry mire model; Northern Ostrobothnia, then all of Finland; Professional features (batch ranking, reports, team access, API).
